## なぜ今回は実装しないのか
- **クロミ カシスショコラ / マイメロ いちごヨーグルト**: 現行販売の可能性は高いが、**UNICOLE に検証済み画像が無い**＋価格不一致（クロミ ¥700 vs データ ¥750）。画像なし表示はルール違反。
- **サーティワン・チュリトス**: 25周年コラボで **2026/5/10 終売**。復活表示は禁止。
- **ソルティキャラメルチュリトス（可視）**: 信頼ソースで **休止中**＋ユーザーが**画像不一致**指摘。ただし公式での休止/終了が未確認、正画像URLも未確定 → 自動 hide/差し替えは不可。
- override 層は**重複統合専用**で、画像付与・displayQuality/reviewStatus 昇格・価格修正・販売状態変更を扱えない。generated 直接編集・crawler・translations 変更は禁止。

→ 今この瞬間に安全に実行できるデータ修正が無い。

## 将来 安全に直すための前提（別フェーズ・人手→設計→実装）
1. **人手: 公式画像の取得と検証**（外部自動保存は禁止）。対象: food-10fodl7 クロミ カシスショコラ、food-1sem5gf マイメロ いちごヨーグルト。`public/manual-images/<food.id>/` に保存し、根拠URL・確認日を記録。
2. **人手/公式: 現行販売と価格の確認**。クロミは ¥700 が正か（データは ¥750）。マイメロは現行性を公式で確認。
3. **ソルティキャラメル（food-5n9awi）**: 公式で「休止/終了」が確認できれば hide、現行なら正しい画像へ差し替え。**公式確認が前提**。
4. **設計: image-override / visibility-override 機構**（duplicate-overrides と同型・全件差分ガード付き）を Claude が別途設計。generated 直接編集なしで「画像差し替え」「可視化」を安全に反映できるようにする。
5. 上記が揃ってから、**1商品ずつ** override に追加 → apply → レビュー → 反映。
