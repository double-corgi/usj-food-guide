## 1. Objective

home-design-v1 の骨格（棚・銘板・大判レール・期間限定枠）はそのまま、視覚品質の問題だけを直す。

達成基準: ロゴが全画面幅で崩れない / 0品ユーザーのファーストビューが「美味しそう」に見える / 棚の1枚1枚が料理として判別できる / 期間限定コレクションが本当に期間限定の商品群になる。

## 2. 修正対象（これ以外は触らない）

visual-review-home-v1.md の指摘番号に対応:

- **P0-1**: ロゴ刻印レイヤーの崩壊（768px以上で金の「レ」がタグラインに重なる）
- **P0-2**: 未取得トーンダウンが強すぎて棚が「茶色くくすんだ写真の壁」になる
- **P1-1**: 棚タイルが小さすぎて料理が判別できない
- **P1-2**: 棚の意味が初見で伝わらない
- **P1-3**: PC左カラム（1280px）の縦の間延び
- **P1-4**: 期間限定コレクションが「ミニオン」を選出する
- **P2-1**: 取得スタンプが小さすぎる（16px→20〜24px）
- **P2-2**: 0品状態の銘板が寂しい（0と0%の突きつけ）
- **P2-3**: 棚の写真品質ばらつき（実装範囲内の改善のみ）
- **P3-a**: 「全商品を見る」の文言リスク

- 前回レビュー残: スタンプ演出のページ読込誤発火 / グローの旧ミントグリーン色

## 3. オーナー確定仕様

### 3.1 ロゴ（P0-1）

- **`::before` / `::after` で `attr(data-logo)` を重ねる現方式を完全廃止**。globals.css の `.home-unicole-logo::before` ブロックと、tsx側の `data-logo` 属性を削除する
- 新方式: **text-shadow 単発の Gold**。Navy(`#071b3a`)本体に、ごく薄い Gold の text-shadow を1つだけ（目安: `1px 1px 0 rgba(253,187,48,0.55)` 程度。値は見た目で微調整可、ただし影は1方向1発のみ）
- 左右の Gold 罫（`h-px w-5 bg-[#fdbb30]`）は維持
- 禁止: 疑似要素での文字重ね / 巨大Gold文字レイヤー / SVGロゴ化 / 画像ロゴ / アイコン追加 / ヘッダー追加 / 厚い縁取り / 多重影 / 3D表現
- 検証: 390 / 430 / 768 / 1280 / 1920 の全幅で、金が文字に正しく追従し、折り返し・ズレ・はみ出しが無いこと

### 3.2 未取得/取得済みの見せ方（P0-2）

差は「未取得を沈める」のではなく「**取得済みを輝かせる**」で作る。

- **未取得（微抑制）**: 彩度85〜90%・明度をわずかに上げる・ほんの少しだけ暖色に寄せる程度（目安: `saturate-[0.88] brightness-[1.03]`、sepiaは入れるなら0.05以下か無し）。**現行の `sepia-[0.18] saturate-[0.56]` は廃止**。未取得も美味しそうに見えることを優先
- **取得済み**: フルカラー＋ **Gold細枠**（ring 1〜2px の `#fdbb30` 系）＋ **20〜24pxのGoldスタンプ** ＋ ごく弱い内側グロー（subtle。光らせすぎない）
- この規則は棚と期間限定コレクションのタイル両方に適用
- 禁止: ロック / ? / 黒塗り / グレースケール / ぼかし / くすみすぎ / 古いアルバム風 / 茶色い写真の壁

### 3.3 棚サイズと枚数（P1-1）

判別性優先:

- モバイル: **2段×4列=8枚** に変更（現行2×5=10）。390pxでタイル約82〜90px角、430pxで自然に拡大
- タブレット(md): 2段×6〜8列の範囲で、タイルが約80px角を下回らないよう調整
- PC(lg): 3段×6列=18枚は維持
- 角丸: 現状維持または少しだけ大きめ。1枚1枚が「料理」として認識できることが合格基準

### 3.4 棚の意味づけ（P1-2）

- 棚の直上または銘板に、短い補助文を1行だけ追加: 「**食べると、棚が色づく。**」（この文言を採用。変更する場合も10文字前後・1行厳守）
- 説明過多にしない。2行以上の説明文・チュートリアル・ツールチップは禁止

### 3.5 0品状態の銘板（P2-2）

- 0品時: 達成率%と進捗ゲージを**表示しない**。「コレクション 0」を巨大に見せない。代わりに誘い文言「**最初の1品を記録すると、棚が色づきます。**」＋「販売中 {total}品（登録分）」の小表示
- 1品以上: 通常表示（コレクション数 / 販売中◯品（登録分）・残り◯ / ゲージ＋%）
- 禁止: 0と0%を大きく突きつける / 成績表のように見せる / 空状態を寂しくする

### 3.6 期間限定コレクションの選出条件（P1-4）

`buildLimitedCollection` を以下に修正する:

**候補商品の条件**（必ずいずれかを満たす商品だけを候補にする）:

- `isLimited === true`
- `salePeriodLabel` がある
- 販売終了日または期間情報がある（`saleEndDate` / `endDate` / `releasePeriod` 等）
- `eventName` / `collaborationName` / キーワードに期間性ワードが含まれる: `25th / 25周年 / 期間限定 / 限定 / イベント / コラボ / ハロウィーン / クリスマス / イースター / 夏 / 冬`

**IP名だけでは期間限定扱いしない**: `ミニオン / マリオ / ハローキティ / ジュラシック・パーク / ハリー・ポッター / スヌーピー / セサミストリート` 単独のグループ名は不採用。ただし限定性ワードが併記されている場合（例「ミニオン・ハロウィーン」）は候補可。

**グループ採用条件**:

- グループ内の限定商品（上記候補条件を満たす商品）比率が **70%以上**
- グループ上限 **24品程度**。超える場合は小さなコンプ単位にならないため次候補グループへ
- 適合グループが無い場合のフォールバック: constants の `featuredLimitedCollection` キーワード → `isLimited && active` 全体（24品以内に収まる場合）→ それも無ければ**セクション非表示**
- 実装後、実際に選出されたコレクション名を確認し最終報告に記載（「ミニオン」が再選出されないこと）
- **`is25thFood()` の復活禁止**。25th固定に戻さない

### 3.7 棚と「今集められるフード」の重複（追加確定仕様）

- 棚に表示した商品（canonical key）は、可能な限り「今集められるフード」レールから除外する
- 除外すると8件に満たない場合のみ重複を許可。その場合も**レール先頭2件は棚と重複させない**

### 3.8 棚の写真品質ばらつき（P2-3）

- 実装範囲内の改善のみ。**画像解析・新規DB・外部API・新規メタデータは禁止**
- 可能な対策例: 既存フィールド（imageMatchScore / imageConfidenceScore / sourceType / priority）での優先順位付け、日替わりseedの範囲調整、カテゴリ分散。コストに見合わなければ「対応見送り」と報告してよい

### 3.9 スタンプ演出の修正（前回レビュー残）

- **ページ読込時の誤発火を修正**: `useFoodLogs` の `ready` が true になるまで `useNewlyStampedKeys` の基準セットを確定しない。読み込み直後に既存取得済みタイルがアニメしないこと
- 演出は「食べた」登録直後の該当タイルのみ・1回限り・900ms以内
- **グロー色修正**: globals.css の `achievement-unlock` キーフレームの `rgba(137, 232, 191, …)`（旧ミントグリーン）を Gold 系 `rgba(253, 187, 48, …)` へ変更
- `prefers-reduced-motion: reduce` での無効化は維持

### 3.10 文言修正（P3-a）

- home-dashboard.tsx の「全商品を見る」見出しを「**登録済みコレクションを見る**」または「**すべて見る**」へ変更（サブテキスト「図鑑に登録された◯種類…」は非断定なので維持可）
- 画面のどこにも「全183品」「全フード」「完全収録」が無いことを確認

### 3.11 未使用コード削除（P3-b）

- `components/home-progress-client.tsx` 内の `HomeHeaderStats` / `HomeProgressStatusClient` / `StatusMini` を、**プロジェクト全体で参照ゼロであることを grep で確認したうえで**削除する。参照が見つかった場合は削除せず最終報告に記載
- あわせて home-dashboard.tsx の `aria-label="ホーム"` 付き div は、`<section>` に戻すか aria-label を外す（roleの無いdivへのaria-labelは無効なため）
