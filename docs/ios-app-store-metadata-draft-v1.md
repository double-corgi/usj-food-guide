## Description候補

ユニコレは、ユニバーサル・スタジオ・ジャパンのフードを探して記録するための非公式フード図鑑アプリです。

商品名、店舗、エリア、価格、期間限定メニューを確認しながら、気になるフードや食べたフードを端末内に記録できます。2026年夏限定コレクションでは、公開確認済みの商品だけを一覧で確認できます。

主な機能:

- フード一覧、検索、店舗別、エリア別の確認
- 商品詳細、価格、店舗、エリア、画像の確認
- 食べたフードの端末内記録
- 期間限定コレクションの進捗表示
- プライバシー設定と問い合わせ導線

このアプリは非公式のフード図鑑であり、ユニバーサル・スタジオ・ジャパン公式アプリまたは公式サービスではありません。

## Review Notes候補

このアプリはUSJフード情報を整理する非公式ガイドです。通常利用にログインは不要です。食べた記録やレビューは端末内に保存され、運営者へ自動送信されません。

管理画面は運営者専用で、一般ユーザーには公開していません。広告表示にはGoogle AdMobとGoogle User Messaging Platformを使用しています。必要な地域では同意確認を行った後に広告を表示します。
