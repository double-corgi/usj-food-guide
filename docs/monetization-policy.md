# 収益化準備メモ

最終更新日: 2026-06-01

現時点では広告SDK、アフィリエイトSDK、課金SDKは導入しません。App Store / Google Play審査前に不要な外部SDKを増やさない方針です。

## 収益化ルール

- 広告枠は `components/ad-slot.tsx` を使い、広告が非表示でもUIが崩れない余白設計にする。
- PR、スポンサー、アフィリエイトはユーザーが判別できるように明示する。
- 広告やPRがランキング、攻略スコア、おすすめに影響する場合は、影響範囲を明記する。
- 広告SDKを追加する場合は、プライバシーポリシー、App Store Privacy、Google Play Data safetyを更新する。

## 表示ラベル

- `広告`
- `PR`
- `スポンサー`
- `アフィリエイトリンク`
