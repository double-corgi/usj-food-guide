## 3. すぐ直すべき項目（高確度・安全）

1. **スチュアート・バケツ アイスの表示重複を override で統合**
   - canonical（残す）: **food-1ksr7hg**「アイスクリーム スチュアート・バケツ スプーン付き」¥950（gallery画像あり）
   - duplicate（隠す）: **food-1qcrkg3**「アイスクリーム スチュアート・バケツ スプーン」¥950（offercard画像）
   - 根拠: 同一商品ライン・同一店舗(アミティ・アイスクリーム)・同一¥950・**同一画像アセット（crop違い）**、両方が現在 canon=true/hidden=false で**二重表示**。前回の重複3ペアと同型の安全な統合。

> これ以外に「今すぐ・無検証で安全」と言える修正は無い（他は価格/現行性/正画像の確証が必要）。

## 4. 保留／要確認にすべき項目（断定修正しない）

- **ボブのワッフルチキンプレート(1ojz6jw) の画像不一致（#7）**: フィルの画像を使用。正しいボブ用画像の有無、そもそもボブ商品が実在するか（フィルの重複でないか）を要確認。確証なしに画像差し替え/統合しない。
- **スチュアート・バーガー 通常(1435vjy ¥2400) vs ビッグ(bcbp5u ¥2300)（#5）**: 両方 BIG 画像。同一(BIG)商品の重複の可能性が高いが、価格が食い違い（どちらが正か不明）。正しい商品構成・価格を確認してから統合/価格修正。
- **ジュラシック バーガー（#2）**: ラプトル2品・モササウルス2品がそれぞれ同一画像。別メニュー（ベーコン&ビーフ/通常、フィッシュ/通常）の正規バリエーションか重複かを要確認。片方は価格欠落。
- **チュリトス大量非表示（#1・#3）**: 終売の期間限定コラボ（鬼滅・呪術・コナン・スパイファミリー・One Piece・サンリオ等）が多く含まれる。**現行品のみを選別する検証が必要**。一括復活は終売・未確認価格を表に出すため不可。
- **画像内価格 vs データ価格（#6）**: 画像OCR検証が必要。確証なしに価格を書き換えない。

## 6. カテゴリ漏れ候補リスト

- **重要な所見**: チュリトス系は **category=churro に正しく分類されている**。友人の「チュリトスカテゴリに出ない」は**カテゴリ誤りではなく可視性（品質ゲート）の問題**。
  - 可視チュリトス＝13/61。残り48件は `canonicalFood=false` かつ大半が `displayQuality=low` / `reviewStatus=pending` で `isVisibleFood`（lib/repositories/foods.ts → filterVisibleFoods）に弾かれている。
  - 例（非表示の有名コラボ churros）: マイメロディ / クロミ / 怪盗キッド / コナン / 鬼滅(炭治郎・禰豆子・伊之助) / 呪術(虚式茈・黒閃) / スパイファミリー / チェンソーマン / ドラえもん / ゾロ抹茶(=ジュラシック緑) など。
- カテゴリ「割当」自体の明確な誤りは churros では未検出。ミニオン/サンリオ/コナン/ジュラシック系も、可視品は概ね妥当なカテゴリ（burger/dessert/drink/churro 等）に入っている。
- → **「カテゴリ漏れ」の実体は主に可視性の過剰 suppress**。真のカテゴリ誤分類は今回の高確度リストには無い。

## 9. 安全な修正方針

**触ってよい（安全層）:**
- `data/duplicate-overrides.json`（override 追記）＋既存オフライン適用スクリプト `scripts/debug/apply-duplicate-overrides.ts`（前回承認済の安全機構）。対象は**表示重複の canonical/hidden 統合のみ**。

**触ってはいけない:**
- `scripts/output/*.generated.json` の直接編集（生成物・git管理。override 経由でのみ反映）。
- `data/translations`、DB、crawler 実行、大規模 crawl、外部画像取得。
- 価格・販売状況の無検証な書き換え。

**override 層で“できないこと”（=今回スコープ外）:**
- チュリトス等の**可視化（promote）**：override は canonical/hidden 統合用で、displayQuality/reviewStatus を覆す機能ではない。可視化は品質パイプライン/レビュー側の判断が必要。
- **画像差し替え・価格修正**：override の範囲外。確証ある場合に個別対応（別計画）。

**優先順位（App Store 提出前）:**
1. スチュアート・バケツ アイス重複の override（今すぐ・安全）。
2. 画像不一致(#7 ボブ=フィル)・スチュアートバーガー重複(#5) の**検証**→確証後に対応。
3. チュリトス可視性(#1・#3)の**現行品選別レビュー**→段階的に promote（要・販売状況確認）。
