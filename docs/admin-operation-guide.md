# UNICOLE 管理画面 かんたん操作ガイド

家族がスマホから商品を追加・修正するときの手順です。

## ログイン

1. `/admin/login` を開きます。
2. 登録済みの管理者メールアドレスを入力します。
3. 届いたログインリンクを開きます。
4. 管理トップ `/admin` が表示されたら準備完了です。

## 商品を追加する

1. 管理トップの「商品を追加」を押します。
2. 商品名、価格、エリア、店舗、カテゴリを入力します。
3. 画像を選びます。画像は保存時に自動で商品カード向けに調整されます。
4. 「今すぐ公開」がONなら、保存後に公開ページへ反映されます。
5. 「保存する」を押します。
6. 保存後は商品詳細画面で「公開ページで確認」を押して見え方を確認します。

## 画像を追加・差し替えする

1. 商品詳細または商品一覧から「編集」を押します。
2. 画像欄で新しい写真を選びます。
3. 「保存する」を押します。
4. 画像を選ばずに保存した場合、今の画像はそのまま残ります。

## 商品を編集する

1. 管理トップの「商品一覧を管理」を開きます。
2. 直したい商品の「詳細」または「編集」を押します。
3. 価格、店舗、カテゴリ、販売期間、画像などを直します。
4. 「保存する」を押します。
5. 保存後は「公開ページで確認」で表示を確認します。

## 間違えた商品を非表示にする

1. 商品一覧または編集画面で「非表示にする」を押します。
2. 確認メッセージで内容を確認します。
3. 非表示にした商品は公開ページから消えます。
4. 管理画面には残るので、あとから「再表示する」で戻せます。
5. 完全削除は使いません。迷ったら非表示にします。

## 公開ページを確認する

1. 管理トップの「公開ページを見る」を押します。
2. 商品一覧や商品詳細で、一般ユーザーに見える表示を確認します。
3. 管理者としてログイン中だけ、下部に管理バーが出ます。
4. 通常ユーザーには管理バーや編集ボタンは表示されません。

## やってはいけないこと

- 同じ商品を重複登録しない。
- 公式情報や現地確認がない商品を販売中として登録しない。
- 未確認の価格を確定価格として登録しない。
- 自動取得の商品を無理に上書きしようとしない。
- 不要になった商品を削除しようとしない。非表示にする。
- 管理メモに個人情報や秘密情報を書かない。
