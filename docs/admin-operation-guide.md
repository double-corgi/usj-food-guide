# UNICOLE 管理画面 運用メモ

## 1. ログイン方法

1. `/admin/login` を開きます。
2. 登録済みの管理者メールアドレスを入力します。
3. 届いたMagic Linkを開きます。
4. ログイン後、`/admin/foods` に移動します。

## 2. 商品を追加する

1. `/admin/foods` の「＋ 商品を追加」を押します。
2. 商品名、価格、エリア、店舗、カテゴリ、販売状態、公開状態を入力します。
3. 画像がある場合は画像ファイルを選びます。
4. 重複候補の警告が出た場合は、同じ商品ではないか確認します。
5. 問題なければ「保存する」を押します。
6. 保存後は商品詳細画面に移動します。

## 3. 画像を登録・更新する

1. 商品追加または編集フォームで画像ファイルを選びます。
2. 画像は保存時に商品カード向けサイズへ自動調整され、WebP形式で保存されます。
3. 画像を選ばずに編集保存した場合、既存画像は維持されます。

## 4. 商品を編集する

1. `/admin/foods` で対象商品の「詳細」を開きます。
2. 「編集」を押します。
3. 内容を修正して「保存する」を押します。
4. 編集できるのは手動追加した `manual_foods` 商品だけです。
5. generated商品は確認のみで、保存できません。

## 5. 非表示にする

1. 手動追加商品の編集画面を開きます。
2. 「非表示にする」を押します。
3. 非表示商品は管理画面には残りますが、公開ページには表示されません。
4. 削除は使いません。再度表示したい場合は「再表示する」を押します。

## 6. 管理メモ

管理メモは管理画面だけに表示されます。公開ページ、検索結果、商品カードには表示されません。

## 7. やってはいけないこと

- 同じ商品を重複登録しない。
- 公式確認できない商品を販売中として登録しない。
- 価格が未確認の商品を確定価格として登録しない。
- generated商品を手動で置き換えようとしない。
- 削除運用をしない。迷ったら非表示にする。
- 管理メモに公開してはいけない個人情報や秘密情報を書かない。
